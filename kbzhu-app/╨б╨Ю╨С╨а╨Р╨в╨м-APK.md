# Как получить APK (3 команды)

Нужен Node.js (nodejs.org, версия LTS) и бесплатный аккаунт на expo.dev.

Откройте терминал В ЭТОЙ ПАПКЕ и выполните:

```bash
npm install
npx eas-cli login
npx eas-cli build -p android --profile preview
```

На вопросы EAS отвечайте «Y» (создать проект, сгенерировать ключ подписи).
Через 10–20 минут в терминале появится ссылка и QR-код на готовый APK.
Скачайте его на телефон и установите (разрешите установку из неизвестных источников).

## Если хочется просто запустить без APK

```bash
npm install
npx expo start
```

и отсканировать QR-код приложением Expo Go.

## Фото еды

В приложении: Профиль → «Распознавание еды по фото» → вставьте ключ Anthropic API.
Остальные функции работают без ключа.
